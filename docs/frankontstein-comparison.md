# FrankONTstein comparison

This assessment compares parent repository `chusj-pigu/nf-core-oncoseq` release `v1.0.2`, commit `a663a10012e467ded972f1b98ded372d5f5ef2fa`, with FrankONTstein `46553118352caa218f82762f74c74ce635220177`, inspected on 20 November 2026. The implementation uses that exact release as its baseline. The parent's `main` and the fork's `main` both point to this commit, and the adaptation PR targets the fork's `main`. FrankONTstein also had an uncommitted QDNAseq memory override of 8 GB, capped at 16 GB. That local change was observed during the comparison.

The table describes source behaviour. Clinical equivalence requires results from the same input data, reference assembly, panels and model versions.

| Area                  | Oncoseq baseline                                                                                                                               | FrankONTstein baseline                                                                                                    | Effect on migration                                                                                                                             |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| Execution             | Generic local/container profiles and scheduler-style GPU options                                                                               | Terraform Batch CPU, GPU and dedicated BAM queues, IAM, registry auth and S3 environment loader                           | The candidate adds a separate stack with separate basecalling/general GPU fleets and maps selectors to Oncoseq process names.                   |
| Image provenance      | 36 image references, including `latest` for ichorCNA, Magick, Ontime and QDNAseq                                                               | Image digest manifest, including locally adapted preparation and reporting images                                         | Candidate pins all 36 current Oncoseq images. Shared tool names can still refer to different software builds.                                   |
| Reference contract    | Genome/cache discovery with download fallbacks and bundled defaults                                                                            | Explicit FASTA, index, enrichment/target BEDs and caller/model resources through a bundle or `steps`                      | Candidate requires explicit clinical caches. Content checksums, object versions and institution-specific panels need a release manifest.        |
| Analysis selection    | Full, realtime, time-series, WGS and cfDNA routing                                                                                             | Primary, secondary and tertiary tiers, with explicit caller/classifier subsets                                            | Tier mappings need deliberate selection. Oncoseq has no equivalent `--callers` contract.                                                        |
| Basecalling           | Dorado 1.3.0, simple or multiplex input, quality filtering, conversion to FASTQ                                                                | Sharded POD5 calling, prepared uBAM export, per-shard demux/trim and tag checks                                           | Confirm trimming, read retention and preserved tags using identical POD5. The fork's image supports SUP v5.2.0 at the software-catalogue level. |
| Clair3 models         | SUP/HAC automatically map to `*_v500` weights                                                                                                  | Bundled v500 or explicitly staged `*_v520_with_mv` weights, pairing checks and dwell-time mode                            | SUP v5.2.0 downstream calling needs a matching model interface and validation.                                                                  |
| Move tables           | Dorado wrapper omits `--emit-moves`                                                                                                            | Move emission and integrity checks support move-aware Clair3                                                              | The current fork cannot reproduce that Clair3 path through its basecalling wrapper.                                                             |
| Targets               | Starts with an enrichment BED and subtracts padding, default 20 kb, to construct `bed_nopad`                                                   | Separate exact target BED and enrichment BED                                                                              | Removing padding from merged intervals may differ from the original target intervals. Compare interval contents before comparing calls.         |
| Small variants        | Clair3, ClairS-TO and DeepSomatic use `bed_nopad`; Clair3 sets SNP minimum AF 0.05                                                             | Clair3 and DeepSomatic use exact targets; explicit DeepSomatic/ClairS-TO indel minimum AF 0.05                            | The candidate now sets both indel minimum AF values to 0.05. DeepSomatic PoN and model arguments still need a command-level comparison.         |
| Somatic consensus     | Per-caller VCFs and downstream concatenation/phasing                                                                                           | Exact normalised DeepSomatic/ClairS-TO alleles, PASS in both callers, scoped to exact targets                             | A consensus result and its independent review table need to be ported if they remain required.                                                  |
| Phasing and SV inputs | Full mode phases variants and haplotags BAMs before SV calling                                                                                 | Independent SV callers on unphased BAMs                                                                                   | Compare support, phasing effects and calls before declaring SV concordance.                                                                     |
| Sniffles              | `--minsupport-auto-mult 0.05`, currently version 2.8.0                                                                                         | Pinned local Sniffles wrapper/image with its own arguments                                                                | Support thresholds and software build differ.                                                                                                   |
| Structural filtering  | SV filtering includes `FORMAT/DV > 4`, excluded regions/genes and report-specific logic                                                        | Native caller outputs plus gene/breakpoint annotation and curated gene-pair navigation                                    | Match both native-call and displayed-finding scope.                                                                                             |
| NASVAR                | Full pipeline with image-bundled reference and paediatric leukaemia configurations                                                             | Tier-specific NASVAR execution and staged assets, with native findings linked to caller evidence                          | Compare panel content, transcripts, MAF sites, repeats and SNV/ITD evidence linking.                                                            |
| CNA input             | QDNAseq and Delly receive `ch_bam_to_process`                                                                                                  | QDNAseq, Delly and HMMcopy use explicit off-enrichment BAMs                                                               | Copy-number signal inputs differ on adaptive-sampling data.                                                                                     |
| CNA bin sizes         | QDNAseq 500 kb, Delly 50 kb, ichorCNA 500 kb                                                                                                   | QDNAseq 100 kb, Delly 100 kb, ichorCNA 1 Mb                                                                               | Bin size, normalisation resources and event-resolution expectations need comparison.                                                            |
| CNA tool coverage     | QDNAseq, Delly and NASVAR; ichorCNA routed in cfDNA mode                                                                                       | Also SubChrom, with a Clair3 prerequisite; ichorCNA available in tertiary hg38                                            | SubChrom and non-cfDNA ichorCNA require workflow additions if selected for this fork.                                                           |
| Classification        | Classy combined output includes blood ALMA, Lamprey, MARLIN and OPTiC, plus other tumour-specific models                                       | Classy plus separately managed compatible Lamprey, ALMA3 and OPTiC paths                                                  | Several requested classifiers already exist upstream. Compare bundled model versions, preprocessing, score thresholds and availability.         |
| Classification input  | Full-mode classification can subsample high-coverage BAMs                                                                                      | Explicit shared preparation and classifier-specific staging                                                               | Sampled coverage and methylation preprocessing can affect classifier scores.                                                                    |
| Methylation/QC        | Classy/modkit and adaptive coverage reports; distinct mosdepth flag/MAPQ presets including MAPQ 60                                             | Indexed 5mC/5hmC bedMethyl and integrated on/off-enrichment QC at MAPQ 0 and 20                                           | Report metrics and standalone methylation deliverables differ.                                                                                  |
| Annotation            | VEP 115.2 image/cache version 115, offline `--everything`; default filter uses MANE, exome AF at most 0.01, consequence and ClinVar text tests | Explicit VEP/population/ClinVar assets, whitelist, review/conflict handling, per-caller metrics and prioritisation tables | Clinical shortlist membership will differ even for identical calls.                                                                             |
| Display filters       | Small-variant table generally requires depth at least 20 outside cfDNA; special ClairS-TO FILTER handling                                      | Native FILTER preserved, separate population-prioritised shortlist and broader consensus review table                     | Validate displayed findings independently from VCF concordance.                                                                                 |
| Reports               | Quarto HTML, Figeno plots, per-tool outputs and PharmCAT                                                                                       | Offline sample summaries, run index, manifest/provenance, native NASVAR findings, molecular and gene-pair review          | Report parity needs an explicit list of retained fields and exports. PharmCAT and upstream visualisations expand the comparison.                |
| Assemblies            | hg19, hg38 and hs1 branches; Classy skipped for hs1                                                                                            | hg38 and hs1, with explicit tool exclusions and hg38-only annotation                                                      | Validate the institutional assembly path first. Baseline hg19 Severus PoN URL refers to an unavailable asset at the pinned upstream commit.     |
| Tests                 | Many local datasets are absent from the checkout, and some tests reference missing modules                                                     | Larger synthetic contract-test suite, with biological and Batch integration validation still described as pending         | Build shared realistic acceptance fixtures and compare result metrics.                                                                          |
